# 🧠 AI学习笔记（产品视角）

## 📌 仓库简介
本仓库用于记录我从**AI产品经理视角**出发，对人工智能相关知识的学习与思考。

不同于算法或工程实现，本仓库更关注：
- AI是什么,为什么能够“回答”问题
- AI能做什么 / 不能做什么
- AI在实际产品中的应用方式
- 如何基于AI能力进行产品设计与决策

---

## 🎯 学习重点

### 一、AI基础认知（产品层理解）
- 什么是大语言模型（LLM）
- AI文本生成的基本原理（概率、解码）
- 训练（Training）与推理（Inference）的区别

### 二、AI产品核心概念
- Prompt设计（提示词工程）
- AI幻觉（Hallucination）
- 上下文窗口（Context Window）
- Token 与成本问题

### 三、AI系统与应用方式
- RAG（检索增强生成）
- AI Agent（基础认知）
- 基于工作流的AI应用
